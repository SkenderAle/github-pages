# Il grande Carnevale · Alessandro Zilli

Due pagine HTML collegate per l'ascolto de *Le Carnaval des animaux* di Camille Saint-Saëns con SMART Board e browser touch.

- **Lezione**: index.html (introduzione di Saint-Saëns in prima persona con voce sintetica facoltativa, 14 quadri, cursori A/B trascinabili, laboratori e orchestra).
- **Sfida dei serragli**: gioco.html (due squadre, tessere audio anonime, 14 animali, due serragli, drag-and-drop e selezione touch, shuffle, punteggio e crossfade).

Per ascoltare le registrazioni originali serve Internet: file di Wikimedia Commons, registrazione Seattle Youth Symphony Orchestra, direttore Vilem Sokol, licenza CC BY-SA 2.0.
