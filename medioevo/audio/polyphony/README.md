# Cantoría Dataset — Virgen bendita sin par

Four synchronized vocal stems used by the educational polyphony mixer:
Tenor (T), Bass (B), Alto (A), Soprano/Cantus (S).

Source: Cantoría Dataset, Helena Cuesta and Emilia Gómez,
Music Technology Group, Universitat Pompeu Fabra.
https://zenodo.org/records/5878677

Piece: Pedro de Escobar, "Virgen bendita sin par".
Dataset license: CC BY 4.0.

These MP3 files are transcoded from the original WAV stems
without trimming, so synchronization between voices is preserved.
